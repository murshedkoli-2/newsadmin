# 🛡️ NewsAdmin — Editorial & Content Administration Dashboard

[![Radix UI](https://img.shields.io/badge/UI-Radix_UI-161618?style=for-the-badge&logo=radix-ui)](https://radix-ui.com/)
[![React Hook Form](https://img.shields.io/badge/Forms-React_Hook_Form-EC5990?style=for-the-badge&logo=react-hook-form)](https://react-hook-form.com/)

A modern editorial content management dashboard for digital news publications. Manage journalists, draft articles, schedule publishing, curate breaking headlines, and inspect readership analytics.

---

## 🌟 Features

- **✍️ Article Editor**: Rich form handling with React Hook Form, Zod schema validation, and image upload management.
- **🗄️ Database Management**: Scalable news articles and categories schema managed via Prisma ORM.
- **📊 Publication Pipeline**: Status workflows (Draft, Under Review, Published, Archived).
- **🎨 Modern Admin UI**: Crafted using accessible Radix UI primitives and Tailwind CSS.

---

## 🚀 Setup & Installation

```bash
git clone https://github.com/murshedkoli-2/newsadmin.git
cd newsadmin
npm install
npx prisma db push
npm run dev
```
